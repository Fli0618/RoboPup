# 7005 / 7007 五孔 M2 最小适配候选

本目录只改原五处板间孔系，V3及原始源文件保持只读。候选供几何与装配评审，未放行制造、连接强度、预紧力、装配扭矩或小跑。

## 真实紧固件

五颗采用可采购型号 **NBK SNS-M2-5-MS**。厂商表列 M2×0.4、头下长5 mm、头直径3.3 mm、头高2 mm、内六角对边1.5 mm；材料SCM435、黑色氧化膜。厂商螺钉最大扭矩0.53 N·m不作为本铝件连接的允许装配扭矩。

[NBK官方尺寸表](https://www.nbk1560.com/images/en/product/miniaturescrew/SNS/SNS_1.pdf)

独立STEP为名义外包络：头和公称大径杆，不伪造螺旋牙、头部倒角、内六角深度或未提供的公差。杆在7005中的体积重叠只允许存在于对应的 R1.00001、Z109.54～113.04 mm局部啮合限界内，螺钉头与其他区域仍参与检查，未整件排除7005。

## 两件上的局部变化

- **7007**：五个原通孔由φ1.98改为设计φ2.2，仅改Z108.04～109.42 mm原通孔段；φ3.6原头座保留，名义头径向余量0.15 mm，座底到出口1.38 mm。φ2.2是本方案设计值，非NBK指定孔径。
- **7005**：采用原五个闭合底孔的解析轴线，底孔φ1.50改为φ1.60，6 mm圆柱深保留，沿用118°钻尖约定；尖深0.48069 mm，尖端Z116.02069 mm。五孔加工语义为M2×0.4，完整有效牙深需选定丝锥、倒角、攻丝退刀和公差后再定，不能把6 mm底孔深称为6 mm完整牙。
- 源7005是1个闭合承载壳和5个开放缩放螺纹显示壳；闭壳定向提升成有效实体，5个旧显示壳移除，用明确的M2×0.4加工表代替。没有假造螺旋牙实体。
- 外轮廓、关节孔、轴线、五孔排列、两板间位置与原材料体系均保留。五孔之外没有其他材料操作。

[OSG官方A-TAP Vol.11目录](https://osg.com.br/en/pdf/machos/A-TAP-High-Efficiency-Multi-Purpose-Tap.pdf)第15、57印刷页（PDF第16、58页）列M2×0.4推荐切削底孔φ1.6。该加工建议与通用JIS参考表的1.63 mm不是同一表，需加工方按材料及丝锥确认，不适用于挤压丝锥。

## 轴向与剩壁

名义座面Z108.04、7007出口Z109.42、7005入口Z109.54 mm；板间名义间隙0.12 mm。5 mm头下长伸入7005约3.5 mm，至圆柱底名义几何距离2.5 mm。两者均不是公差后的有效牙长或盲孔底余量证明。

`geometry_change_evidence.json`记录逐孔除料体积、孔座底厚与36个径向样本。`remaining_drill_bottom_wall.json`记录各孔轴心钻尖至背面的剩壁；这是轴心测量，不代表所有孔边最小壁厚或强度合格。

对STEP读回的几乎重合全件反向差布尔，7007发生失败；因此除料体积采用有效闭实体输入与读回体积差，局部性由五个明确有限刀具体的构造记录证明，未编造反向差布尔通过。

## 装配检查范围

`static_and_tool_checks.json`包含两件读回后各螺钉静态检查，以及对全部未替换源叶件、保留源紧固件、V3所有接口和硬件及三个保守电机本体的检查。原缩放螺钉186由五颗M2替换；源7005实例192由新件替换。

工具只核查**对边1.5 mm六角直杆的必要通道**：用半径1.5/√3 mm圆柱包住360°转动及沿轴线插入/退出，Z26.04～107.04 mm，假设进入头部1 mm。真实内六角深度、扳手弯头、夹持杆、把手与手部空间尚未确认，直杆通道通过也不表示完整工具操作通过。螺钉头/杆另外检查向−Z退出20 mm的连续圆柱扫掠。

## 文件

- `7005_V4_M2_pilot_1p6.step`、`7007_V4_M2_clearance_2p2.step`：两件有效单实体候选。
- `plate_SNS_M2_5_MS_1.step`～`plate_SNS_M2_5_MS_5.step`：五颗独立名义包络。
- `7005_7007_M2_joint_candidate.step`：本连接局部候选总装。
- `plate_joint_manifest.json`：替换关系、源文件SHA256、名义螺纹限界和未放行项。

全套最终工序仍需与7009输出螺钉工具通道、小腿销拆卸路径一起验证；这五处适配本身不放行整腿快拆或运动。
